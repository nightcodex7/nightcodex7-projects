Yet Another LuCI for OpenWrt

Manage OpenWrt routers from your Android phone.

A native Android client for OpenWrt router administration — package management (OPKG/APK), firewall control (iptables & nftables), network topology visualization, wireless client management, and multi-router support, all over ubus/RPCD.

features

cat FEATURES.md
  • Package ManagementInstall, upgrade, and remove packages via OPKG and APK backends.
  • Firewall ControlFull firewall rule management supporting both fw3 (iptables) and fw4 (nftables).
  • Network TopologyVisualize your network layout for both DSA and swconfig switch configurations.
  • Wireless StatusWPA3-SAE aware wireless status and connected-client management.
  • Multi-Router SupportManage several OpenWrt routers from a single app
  • Secure StorageRouter credentials stored with hardware-backed encryption on-device — never transmitted.
